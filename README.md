## Как открыть

**Сайт** — одна страница-лендинг. Локально она открывается по адресу из **`APP_HOST`** в `.env` (в примере — `http://evahelp.docker.local`) или по `http://localhost`, порт **80**.

**Админка WordPress** — служебная панель. Адрес заканчивается на `/wp-admin/`. Язык интерфейса — **русский** (`WP_LOCALE=ru_RU`).

Учётная запись администратора задаётся при первой установке переменными **`WP_ADMIN_USER`**, **`WP_ADMIN_PASSWORD`** и **`WP_ADMIN_EMAIL`**. В примере `.env` это логин **`admin`** и пароль **`pass`**. Повторный запуск контейнера эти значения не перезаписывает.

**Пользователь guest** видит только список заявок. Демо-доступ написан на странице **О проекте** (`/app-description/`): логин **`guest@mil.ru`**, пароль **`guest`**. После входа открывается список заявок, остальные разделы панели для этой роли закрыты.

**Mailpit** — ящик перехваченных писем: http://localhost:8025. Письма туда попадают, когда в `.env` стоит **`MAILPIT_ENABLED=1`**.

## Как устроен экран

### Лендинг

Тёмная страница на шрифте Manrope. Меню ведёт к блокам той же страницы, отдельные разделы каталога не открываются.

| Часть экрана | Что здесь |
| --- | --- |
| **Шапка** | Логотип с буквой, название и подпись, меню разделов, телефон и кнопка **Вызвать**. На узком экране пункты меню прячутся за кнопку-бургер. |
| **Основная область** | Первый экран, услуги, цены, о компании, шаги, преимущества, вопросы, контакты и форма заявки. |
| **Подвал** | Название, подпись, телефон, ссылки на политику и согласие, подпись Telegram. |
| **Нижняя панель** | Две кнопки: **Позвонить** и **Заявка**. |
| **Справа внизу** | Ссылка **О проекте** — страница с демо-доступом в админку. |

Прямой адрес карточки услуги, цены, шага, вопроса, преимущества или заявки возвращает на главную. Эти записи живут только внутри лендинга и в админке.

### Админка

| Часть экрана | Что здесь |
| --- | --- |
| **Слева** | Меню WordPress. Рабочие разделы лендинга собраны в пункт **EvaHelp** (иконка автомобиля). |
| **Основная область** | Обзор, форма «Данные сайта», список карточек или карточка заявки. |
| **Счётчик у «EvaHelp» и у «Заявки»** | Сколько заявок в статусе **Новая**. Пока таких нет, число скрыто. |

У пользователя **guest** слева остаётся только **EvaHelp → Заявки**. Консоль, записи, страницы, настройки и «Данные сайта» для него скрыты.

## Карта разделов админки

Сверху вниз, как в меню **EvaHelp**:

| Пункт | Зачем |
| --- | --- |
| **Обзор** | Сводка: сколько новых и всех заявок, сколько услуг, цен и вопросов. Рядом — телефон, почта заявок, Telegram, WhatsApp и режим работы, как они сейчас записаны. |
| **Заявки** | Заявки с формы на сайте. Можно фильтровать по статусу, открыть карточку, сменить статус или удалить. |
| **Данные сайта** | Тексты, контакты и фотографии лендинга. Пункт виден администратору. |
| **Услуги** | Карточки блока «Когда вызывают эвакуатор». |
| **Цены** | Карточки блока «Сколько примерно стоит». |
| **Преимущества** | Карточки блока «Почему вызывают нас». |
| **Шаги** | Пункты блока «От заявки до доставки». |
| **Вопросы** | Вопросы и ответы в FAQ. |

Обычные **Записи** WordPress на лендинг не выводятся. Страницы **Политика**, **Согласие** и **О проекте** лежат в **Страницы** и открываются по своим адресам.

## Лендинг

### Шапка и низ экрана

| Элемент | Что произойдёт |
| --- | --- |
| Логотип | На главной прокручивает к началу страницы. С документа — возвращает на главную. Буква в кружке берётся из поля **Буква в логотипе**. |
| Пункт меню | Прокручивает к блоку: **Услуги**, **Цены**, **О компании**, **Как работаем**, **FAQ**, **Контакты**. |
| Телефон в шапке | Звонок по номеру из поля **Телефон для звонка**. На экране показывается **Телефон на сайте**. |
| **Вызвать** | Прокручивает к форме заявки. |
| Бургер | Открывает и закрывает меню. Повторное нажатие, выбор пункта или клавиша **Esc** меню закрывают. |
| **Позвонить** внизу | Тот же звонок, что и телефон в шапке. |
| **Заявка** внизу | Прокручивает к форме. |
| **О проекте** | Открывает `/app-description/`. |

При прокрутке шапка становится плотнее. Блок **Преимущества** на странице есть, отдельного пункта в меню шапки у него нет: он стоит между «Как работаем» и FAQ.

### Первый экран

Надзаголовок, заголовок, текст, кнопка **Позвонить**, кнопка **Вызвать эвакуатор**, крупный телефон и до трёх фактов (значение и подпись). Справа — главное фото и подпись к нему.

Пустой факт на сайт не выводится. Если в **Данных сайта** фото не выбрано, берётся картинка из темы.

### Услуги

Сетка карточек. У карточки — иконка, название и текст. На сайте видны только **опубликованные** записи, по полю **Порядок** (меньшее число выше), при равном порядке — по дате создания.

Стартовый набор, если список был пуст: после поломки, после ДТП, перевозка автомобилей, внедорожники, межгород, сложная погрузка.

### Цены

Три вида карточек в стартовом наборе: легковой (**от 1 500 ₽**), кроссовер (**от 2 000 ₽**, выделена, бейдж **Частый заказ**), межгород (**от 50 ₽/км**). Под сеткой — примечание из **Данных сайта**.

Бейдж виден, когда карточка **выделена** и подпись бейджа не пустая. Сумма — отдельное поле, заголовок — название тарифа, основной текст — пояснение.

### О компании

Два абзаца и список пунктов. Пункты задаются одним полем: **одна строка — один пункт**. Справа три фото. Если фото в админке не выбрано, показываются картинки из темы.

### Как работаем

Нумерованный список. Номер на сайте — позиция в списке (1, 2, 3…), он сам в заголовок не пишется. Стартовые шаги: заявка, расчёт стоимости, выезд эвакуатора, доставка автомобиля.

### Преимущества

Карточки с иконкой, как у услуг, своим набором иконок. Стартовый набор: быстрая подача, работа 24/7, опытные водители, собственная техника, без скрытых доплат.

### FAQ

Раскрывающиеся вопросы. Первый в списке открыт сразу, остальные свёрнуты. Заголовок записи — вопрос, основной текст — ответ.

### Контакты

Три карточки:

| Карточка | Откуда текст |
| --- | --- |
| **Телефон** | **Телефон на сайте**, ссылка на звонок. |
| **Мессенджеры** | Текст про мессенджеры и кнопки **Telegram** / **WhatsApp**. Пустая ссылка кнопку скрывает. |
| **Режим работы** | Поле **Режим работы**. |

### Заявка

Форма внизу страницы. Поля: **Имя**, **Телефон**, **Откуда забрать**, **Куда доставить**, **Ситуация**, галочка согласия со ссылкой на текст согласия.

Телефон набирается в виде `+7 (XXX) XXX-XX-XX`. Префикс `+7` остаётся в поле.

| Что ввели | Что произойдёт |
| --- | --- |
| Имя короче 2 символов, телефон не из 11 цифр с семёрки, адрес или ситуация короче 3 символов, галочка снята | Над формой красная подсказка: проверить имя, телефон, адреса и согласие. Заявка не сохраняется. |
| Всё заполнено | Кнопка на время отправки блокируется. Заявка уходит без перезагрузки страницы. |
| Сервер принял заявку | Зелёная подсказка: «Заявка принята. Перезвоним, уточним детали и назовём стоимость до выезда.» Поля очищаются, телефон снова `+7`. |
| С одного адреса больше 8 заявок за час | «Слишком много заявок с этого адреса. Позвоните, пожалуйста.» |
| Сеть или сервер недоступны | «Не получилось отправить заявку. Позвоните нам.» |

Если скрипт формы не загрузился, та же форма уходит обычной отправкой и возвращает на главную к блоку заявки: зелёная плашка при успехе, красная — если сервер заявку не принял.

Заявка сохраняется в админке и при этом может уйти письмом на адрес **Куда отправлять заявки**. В письме — имя, телефон, откуда, куда, ситуация и ссылка на карточку. Если почта не настроена или письмо не ушло, заявка всё равно остаётся в списке, в карточке будет пометка **Не отправлено, заявка сохранена в админке**.

## Админка

### Обзор

**EvaHelp → Обзор**. Пять плиток ведут в списки: новые заявки, все заявки, услуги, цены, вопросы. Ниже таблица текущих контактов и последние заявки: имя с телефоном, маршрут «откуда → куда» и статус.

### Данные сайта

**EvaHelp → Данные сайта**. Кнопка внизу — **Сохранить данные**. Четыре группы полей:

| Группа | Что меняет на сайте |
| --- | --- |
| **Контакты и компания** | Название, буква логотипа, подпись, оба телефона, Telegram и его подпись, WhatsApp, почта в документах, почта заявок, оператор персональных данных (именительный и дательный падеж), город, режим работы, текст про мессенджеры. |
| **Первый экран** | Заголовок вкладки браузера, описание для поисковиков, надзаголовок, заголовок, текст, подпись и описание главного фото, три факта. |
| **Тексты разделов** | Надзаголовки, заголовки и вводные тексты услуг, цен, компании, шагов, преимуществ, FAQ, контактов и формы. Пункты «о компании» — по одному на строку. |
| **Фотографии** | Главное фото и три фото блока «О компании», плюс подписи к ним. **Выбрать изображение** берёт файл из медиатеки. **Фото по умолчанию** возвращает картинку темы. |

Короткое поле обрезается примерно до 300 символов, многострочное — до 4000. Буква логотипа — до двух символов.

### Карточки на лендинге

В каждом списке колонки: название, текст, **Порядок**, дата. У услуг и преимуществ есть колонка **Иконка**, у цен — **Сумма**.

Редактор обычный, блочный редактор для этих записей выключен.

| Раздел | Поля карточки |
| --- | --- |
| **Услуги** | Заголовок, текст, **Порядок**, иконка: поломка, ДТП, перевозка, внедорожник, межгород, сложная погрузка. |
| **Преимущества** | Заголовок, текст, **Порядок**, иконка: быстрая подача, круглосуточно, водители, своя техника, без доплат. |
| **Цены** | Заголовок, пояснение, **Сумма**, **Бейдж**, галочка **Выделить карточку**, **Порядок**. |
| **Шаги** | Заголовок, текст, **Порядок**. |
| **Вопросы** | Вопрос в заголовке, ответ в тексте, **Порядок**. |

**Порядок** — число в блоке «Атрибуты». Чем меньше, тем выше карточка на лендинге. Черновик в списке админки остаётся, на сайт попадают опубликованные записи.

Удаление карточки убирает её с лендинга. Остальные блоки не затрагиваются.

### Заявки в админке

Список: **Заявки**. Над таблицей вкладки **Все**, **Новая**, **В работе**, **Выполнена** — с количеством.

| Колонка | Смысл |
| --- | --- |
| **Заявка** | «Имя — телефон». Это заголовок записи. |
| **Телефон** | Номер, по нему можно позвонить из админки. |
| **Откуда** / **Куда** | Адреса из формы. |
| **Ситуация** | Текст из поля «Ситуация». |
| **Статус** | **Новая**, **В работе** или **Выполнена**. |
| **Дата** | Когда заявка пришла. |

Под строкой — быстрые ссылки на два других статуса. В карточке те же поля, плюс галочка согласия, IP и пометка, ушло ли письмо. Заголовок при сохранении снова собирается из имени и телефона.

Новая заявка с сайта всегда получает статус **Новая**.

Удаление заявки стирает запись сразу. Вернуть её из корзины нельзя: у роли **guest** корзины в этом списке нет, удаление идёт мимо неё.

На **Консоли** WordPress виджет **Заявки на эвакуатор** показывает число новых и пять последних.

### Пользователь guest

Роль называется **Просмотр заявок**.

| Действие | Что произойдёт |
| --- | --- |
| Вход | Сразу список заявок. |
| Чужой адрес админки | Возврат к списку заявок. |
| Открыть карточку на редактирование | Тоже возврат к списку. Править поля guest не может. |
| **Удалить** в строке или массово | Запись стирается из базы. Перед удалением браузер спрашивает подтверждение. |
| Менять статус, тексты сайта, карточки | Эти действия роли недоступны. |

Демо-логин и пароль показаны на публичной странице **О проекте**.

## Документы

В подвале две ссылки. Страницы открываются в той же шапке и том же подвале, что и лендинг.

| Страница | Адрес | Что внутри |
| --- | --- | --- |
| **Политика обработки персональных данных** | `/politika/` | Текст политики. Имя оператора, телефон, почта и город подставляются из **Данных сайта**. |
| **Согласие на обработку персональных данных** | `/soglasie/` | Текст согласия. Оператор в дательном падеже и почта — тоже из **Данных сайта**. |
| **О проекте** | `/app-description/` | Ссылка на вход в админку, логин и пароль guest, короткое описание его прав. В меню лендинга её нет, вход — кнопка **О проекте**. |

В тексте политики и согласия можно оставить короткие вставки, они заменяются при показе страницы:

| Вставка | Что подставится |
| --- | --- |
| `[kov_phone]` | Телефон на сайте, ссылкой на звонок. |
| `[kov_email]` | Почта в документах, ссылкой mailto. |
| `[kov_operator]` | Оператор, именительный падеж. |
| `[kov_operator_to]` | Оператор, дательный падеж. |
| `[kov_city]` | Город. |

Краткое описание страницы (цитата в редакторе страницы) попадает в meta description.

Несуществующий адрес показывает экран **Страница не найдена** и кнопку **На главную**.

## Запуск

Нужны Docker и файл `.env` в корне репозитория. Его собирают из `.env.example`.

```bash
make up
```

Поднимаются три сервиса:

| Сервис | Зачем | Порт на компьютере |
| --- | --- | --- |
| **application** | WordPress на PHP 8.5. Корень репозитория смонтирован в контейнер. | **80** |
| **database** | MariaDB 11.8. База, пользователь и пароль — из `.env`. При первом создании тома выполняется `docker/mariadb/db.sql`. | **3306** |
| **mailpit** | Приём писем, если включён перехват. | **8025** (интерфейс), **1025** (SMTP) |

Тема лежит в `public/wp-content/themes/evahelp`. Код лендинга, заявок и меню админки — там.

Остановить контейнеры, не трогая данные: `make stop`.  
`make down` удаляет контейнеры **и тома**, включая базу.

Пока контейнеры запущены:

```bash
make wp CMD="plugin list"
make rewrite-flush
make cache-flush
```

`make wp` выполняет WP-CLI внутри контейнера приложения.

### Переменные `.env`

| Переменная | Зачем |
| --- | --- |
| **`APP_HOST`** | Имя сайта для PHP, в примере `evahelp.docker.local`. |
| **`APP_PATH`** | Куда внутри контейнера смонтирован репозиторий. |
| **`DB_CONNECTION`**, **`DB_HOST`**, **`DB_PORT`**, **`DB_DATABASE`**, **`DB_USERNAME`**, **`DB_PASSWORD`** | Доступ к MariaDB. Хост внутри сети Docker — `database`, порт `3306`. |
| **`WP_TABLE_PREFIX`** | Префикс таблиц. Пустое значение означает `wp_`. |
| **`WP_LOCALE`** | Язык сайта, для этого проекта `ru_RU`. |
| **`WP_TITLE`**, **`WP_ADMIN_USER`**, **`WP_ADMIN_PASSWORD`**, **`WP_ADMIN_EMAIL`** | Название и администратор первой установки. |
| **`WORDPRESS_CRON_ENABLED`** | **`1`** — отложенные задачи WordPress проверяются раз в минуту. **`0`** — они запускаются, когда кто-то открывает сайт. |
| **`MAILPIT_ENABLED`** | **`1`** — письма перехватывает Mailpit. **`0`** — перехвата нет. Контейнер mailpit при этом всё равно в составе проекта. |
| **`MAILPIT_HOST`** | Куда слать перехваченную почту, в примере `mailpit:1025`. |

Пароли из `.env` в инструкцию сверх примера не копируйте: боевые значения хранятся только на сервере.

## Частые вопросы

**Где поменять телефон и заголовок первого экрана?**  
**EvaHelp → Данные сайта**, группы **Контакты и компания** и **Первый экран**. После **Сохранить данные** главная сразу показывает новые значения.

**Почему карточка есть в админке и её нет на сайте?**  
На лендинг попадают опубликованные услуги, цены, преимущества, шаги и вопросы. Черновик остаётся только в списке админки.

**Как поменять порядок карточек?**  
В карточке поле **Порядок**: меньшее число стоит выше. В списке админки колонка **Порядок** показывает то же число.

**Почему бейджа на цене нет?**  
Бейдж рисуется вместе с выделением карточки. Нужны галочка **Выделить карточку** и непустой **Бейдж**.

**Куда делась заявка с сайта?**  
В **EvaHelp → Заявки**, статус **Новая**. На консоли то же число в виджете и в оранжевом счётчике у пункта меню.

**Почему письмо о заявке не пришло, а в админке заявка есть?**  
Так и задумано: сначала запись, потом попытка письма. В карточке строка **Письмо** покажет, ушло оно или нет. Для локальной проверки включите **`MAILPIT_ENABLED=1`**, перезапустите контейнеры и смотрите http://localhost:8025. Адрес получателя — поле **Куда отправлять заявки**.

**Почему форма пишет «слишком много заявок»?**  
С одного IP за час принимается 8 заявок. Дальше сайт просит позвонить. Через час счётчик начинается заново.

**Почему после входа guest сразу список заявок?**  
Роль **Просмотр заявок** открывает только этот список. Обзор, данные сайта и остальные меню WordPress для неё закрыты. Удалить заявку можно, править — нет.

**Можно ли вернуть удалённую заявку?**  
Нет. Удаление убирает запись из базы.

**Почему политика показывает короткое имя в квадратных скобках?**  
В тексте должны стоять вставки `[kov_operator]`, `[kov_phone]`, `[kov_email]`, `[kov_city]`, `[kov_operator_to]`. Они подставляют поля из **Данных сайта**. Обычный текст в квадратных скобках другого вида на странице останется как есть.

**Где лежат картинки, если в админке фото не выбирали?**  
В теме: `public/wp-content/themes/evahelp/assets/img/`. Выбор в **Фотографиях** подменяет их файлом из медиатеки WordPress.
